# 학습 기반 연구

[연구 전체 흐름](../README.ko.md) · [Research overview](../README.md) · [재현 가이드](../reproduction/README.ko.md) · [계열별 한계와 남은 문제](limits.md)

이 문서는 학습으로 행동 판단을 만든 연구의 경로와 성과를 정리합니다. 학습이 더 이상 점수를 올리지 못하는 이유는 [계열별 한계와 남은 문제](limits.md)에서 따로 다룹니다.

## 초기 학습 정책 연구

초기 neural/MCTS 연구는 작은 행동 가치망으로 유망 후보를 찾고 시뮬레이션 예산을 배분하려 했습니다. 오프라인 지표가 실제 플레이 개선으로 잘 이어지지 않자, 모델이 실제로 방문한 상태와 선택이 갈리는 경계의 자료를 보강하고 행동 간 가치 차이를 학습하는 쪽으로 옮겨 갔습니다. [출처 X4](sources.md#x36-과거-자료)

- **행동 차이 학습:** Structured-V/CAA(파라미터 72,578개)는 당시 X36 대비 독립 1,000판에서 **+23.8점**, CI [14.5, 33.4]였습니다.
- **G3 기반 희소 보정:** 독립 5,000쌍에서 **1795.41 대 G3 1789.24**, 차이 +6.17, CI [3.30, 8.99]였습니다. 행동 변경 범위를 넓히면 잘못된 보정의 비용이 커졌습니다. [출처 X5](sources.md#x36-과거-자료)
- **이후의 한계:** 상태·자료·규모 확대, 반복 개선·앙상블, 직접 보상 학습(DPI/AWR)은 작은 평가나 오프라인 지표의 이득이 독립 게임 평가로 이어지지 않았습니다. 신경망을 rollout의 후속 정책으로 쓰면 매 결정의 반복 호출 비용이 너무 컸습니다. [출처 X6](sources.md#x36-과거-자료)

과거 QStar `v20`, 여러 G4 실험, `adventure_v5_continuation`은 LYRA의 V₂₀나 VELA의 후속 버전이 아닙니다.

## LYRA의 학습 경로

LYRA는 모델이 플레이하며 모은 자료로 다음 모델을 학습하는 반복 자기 개선을 목표로 시작했습니다. LYRA v1의 경로는 **VELA v4.2 Hinge 교사 → Actor → DAgger → 초기 가치망 V₀ → 반복 가치 갱신 → V₂₀ / π₂₀**입니다. [LYRA v1 보고서](../lyra-v1/report-ko.md)

| 전환 | 결과 |
|---|---|
| 정책 모방과 후속 PPO | 모방 정책은 Hinge보다 낮았고, 해당 PPO 처방도 개선을 만들지 못함 |
| 가치망 + 실제 덱 전이의 기대값(1-step) | 행동을 직접 복사하는 대신 가치 추정과 정확한 전이를 결합하는 경로 확보 |
| 반복 가치 갱신 → π₂₀ | **LYRA v1.** 제어변량 보정 대표 평균 약 1879점, Hinge 대비 서로 다른 두 평가 시드 집합에서 **+1.49 / +1.30점**(각 10K쌍) |

1-step 정책은 같은 상태의 행동들이 공유하는 가치 오차가 비교 과정에서 상쇄되기 때문에 작동합니다. 이 성질은 이후 정체를 이해하는 출발점이 됐습니다. [출처 L1](sources.md#lyra-연구와-후속-방향)

## LYRA v2: 같은 처방의 독립 가치 반복

SCALE-VI는 크기가 다른 가치망을 **V₀부터 같은 처방으로 각자 가치 반복**해 비교했습니다. 반복마다 자가 대국 2,000판에서 상태를 뽑고, 현재 모델의 1-step 기대값으로 정답을 다시 만들어 이어 학습했습니다.

π₂₀ 대비 수준은 새 시드 10K쌍의 봉인 평가(다중 보정 동시 CI)로 읽습니다.

| 비교 | 보정 대응 차이 | 동시 CI |
|---|---:|---|
| M₂₀ − π₂₀ | +0.64점 | [0.19, 1.08] |
| M₂₀ − S₂₀ | +0.46점 | [0.02, 0.90] |
| **M₄₀ − π₂₀** | **+1.00점** | [0.53, 1.46] |
| M₄₀ − M₂₀ | +0.35점 | [−0.04, 0.74] |

- 처방을 바꾸지 않고 반복한 15.4M 모델이 π₂₀을 넘었고, M₄₀을 **LYRA v2**로 배포했습니다. 배포 정밀도(FP32)로 다른 새 시드 10K쌍을 다시 평가해도 +1.08점(SE 0.19)이었습니다. [LYRA v2 보고서](../lyra-v2/report-ko.md)
- 개발 평가에서 두 크기 모두 V₈ 무렵부터 개선이 크게 둔화됐습니다. M₂₀→M₄₀의 추가 개선은 확인되지 않았습니다.
- 학습 시드를 바꾼 반복에서도 15.4M이 5.5M보다 높았습니다(+0.88, CI [0.25, 1.50]). 같은 처방의 61M은 15.4M과 같은 수준이었습니다(V₈ 차이 +0.03, 동시 CI [−0.67, +0.73]). M의 1-step 추론 비용은 π₂₀의 약 2.3배입니다.
