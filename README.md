# Adventure v2

어드벤처 게임에서 주사위와 카드의 다음 선택을 추천하는 웹앱입니다. 현재 위치·주사위·카드를 직접 입력하는 **수동 모드**와, 누른 주사위·카드의 결과를 처리하는 **자동 모드**를 지원합니다. 자동 모드에서도 행동은 사용자가 선택합니다.

## 모델 선택

| 모델 | 계산 방식 | 평균 기록 | 추천 계산 시간 |
| --- | --- | ---: | ---: |
| **VELA v4** | CPU로 다음 상황을 전개해 행동 평가 | 약 1,875점 | 약 0.5~0.7ms |
| **X36 · G3** | CPU 또는 GPU로 여러 번 시뮬레이션해 예상 점수 계산 | 약 1,860점 | 약 14~551ms · GPU 높음 |

평균 기록은 서로 다른 평가에서 얻은 참고값입니다. 계산 시간은 i5-11500·RTX 3060·Chrome에서 게임 상태 3개를 측정한 중앙값 범위이며, 최초 로딩은 제외했습니다. 기기와 게임 상황에 따라 달라집니다.

VELA는 처음에 약 **813MB**의 모델을 불러옵니다. 웹사이트에서는 브라우저 저장에 동의하면 다음 접속부터 저장된 모델을 재사용합니다. 로컬 실행에서는 프로젝트의 모델 파일을 사용하며 브라우저에 추가로 저장하지 않습니다. VELA의 행동별 평가값은 선택의 유리함을 나타내며 최종 점수 예측은 아닙니다. 모델 선택을 취소하면 추천 없이도 사용할 수 있습니다.

## 내 PC에서 실행

**Node.js 22 이상**이 있으면 별도 패키지 설치나 빌드 없이 실행할 수 있습니다.

1. 프로젝트를 내려받아 압축을 풉니다.
2. **VELA를 사용하려면** GitHub 프로젝트의 **Releases**에서 해당 버전의 모델 파일 `model.bin.gz`를 별도로 다운로드합니다. **압축을 풀지 말고** 프로젝트의 `public/models/vela-v4/` 폴더에 넣으세요. 최종 파일 경로는 `public/models/vela-v4/model.bin.gz`입니다. X36 · G3만 사용한다면 이 단계는 건너뛰어도 됩니다.
3. 프로젝트 폴더에서 터미널을 열고 다음을 실행합니다.

   ```sh
   node scripts/serve.mjs
   ```

4. 브라우저에서 **[http://127.0.0.1:4173/](http://127.0.0.1:4173/)**을 엽니다.

`npm start`로도 실행할 수 있습니다. 사용하는 동안 터미널을 켜 두고, 종료할 때는 `Ctrl+C`를 누르세요. `index.html`을 직접 더블클릭하는 `file://` 방식은 지원하지 않습니다.

## 사용 도움말

화면의 **도움말**에서 조작법과 단축키를 확인할 수 있습니다. 문제가 발생하면 도움말 하단의 **진단 정보 저장 → 파일 저장**으로 받은 파일과 발생 상황을 함께 전달해 주세요. 진단 파일은 자동 전송되지 않습니다.
