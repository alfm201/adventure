# 彩虹島大冒險助手 | AI 骰子與卡牌策略建議

[한국어](../../README.md) · [English](README.en.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md) · **繁體中文**

這是一款為《彩虹島物語》的「彩虹島大冒險」提供擲骰與用牌建議的網頁工具。支援三種模式：**輔助**模式讀取你分享的遊戲畫面，**手動**模式由你自行輸入遊戲狀態，**自動**模式則在工具內模擬你選擇的擲骰或用牌結果。實際遊戲仍需由你親自操作。

本說明提供繁體中文版本；網頁介面的中文選項目前為簡體中文。

輔助模式的**語音提示**支援韓語、英語、日語和中文，可選擇女聲或男聲。下載前可以確認語音包的容量，並選擇是否儲存在瀏覽器中，也能隨時刪除已儲存的語音包。提示音訊皆使用 Gemini 3.8 Flash TTS 預先合成。

## 選擇模型

| 模型 | 評估方式 | 平均分數 |
| --- | --- | ---: |
| **LYRA · v1（研究版）** | 在 CPU 或 GPU 上結合神經網路與單步搜尋，評估各項行動 | 研究測試中約 1,879 分 |
| **VELA · v4.2** | 在 CPU 上推演後續局面，評估各項行動 | 約 1,877 分 |
| **X36 · G3** | 在 CPU 或 GPU 上反覆模擬，比較不同選擇 | 約 1,860 分 |

以上平均分數來自不同評估，僅供參考。計算時間會因裝置效能和當前遊戲局面而異。

預設選擇 VELA。LYRA 為研究版模型，執行裝置可設為自動、CPU 或 GPU。選擇自動時，會優先使用可用的 GPU；若初始化或推論失敗，則改用 CPU。

首次使用時，VELA 需要載入約 **68 MB** 的模型套件，LYRA 約為 **31 MB**。使用線上網站時，如果同意將模型儲存在瀏覽器中，下次造訪即可重複使用。工具確認最新模型資訊後，會先清除不相容的舊版模型資料。在自己的電腦上執行時，直接使用專案中的模型檔案，不會在瀏覽器中額外儲存一份。LYRA 切換 CPU 或 GPU 時，使用的是同一份模型套件。

各項行動的評估值可用來比較不同選擇的優劣。預估最終分數，是持續依照所選模型的建議行動時的預測結果。VELA v4.2 和 LYRA v1 分別使用依各自策略訓練的專用分數預測器。遊戲結束後，會顯示實際分數。也可以取消模型選擇，在不顯示行動建議的情況下使用工具。

## 在自己的電腦上執行

安裝 **Node.js 22 或更新版本**後，不必另外安裝相依套件或建置專案，即可執行。

1. 下載專案並解壓縮。
2. 從下方的 **GitHub Releases** 下載要使用的模型，**不要解壓縮模型檔案**，直接放到指定路徑。若只使用 X36 · G3，可以略過此步驟。
   - **[VELA v4.2](https://github.com/alfm201/adventure/releases/tag/vela-v4.2)：** `model.bin.gz` → `public/models/vela-v4.2/model.bin.gz`
   - **[LYRA v1](https://github.com/alfm201/adventure/releases/tag/lyra-v1)：** `lyra-v1.bin.gz` → `public/models/lyra-v1/lyra-v1.bin.gz`
3. 在專案資料夾中開啟終端機，執行以下指令：

   ```sh
   node scripts/serve.mjs
   ```

4. 在瀏覽器中開啟 **[http://127.0.0.1:4173/](http://127.0.0.1:4173/)**。也可以透過 `PORT` 環境變數指定其他連接埠。

也可以使用 `npm start` 啟動。使用期間請保持終端機開啟，結束時按 `Ctrl+C`。不支援連按兩下 `index.html`、透過 `file://` 直接開啟的方式。

本專案自有的 VELA、LYRA 模型可自由用於其他服務。模型套件內第三方元件的使用與再散布條件，請參閱[授權與使用許可說明](../../LICENSING.md)（英語）。

模型檔案仍會透過 [GitHub Releases](https://github.com/alfm201/adventure/releases) 提供。如需從 Cloudflare 下載，請向 `https://adventure.alfm201.workers.dev` 的以下路徑傳送 `GET` 請求。

| 模型 | Cloudflare 下載路徑 |
| --- | --- |
| VELA v4.2 | [/models/vela-v4.2/model.bin.gz](https://adventure.alfm201.workers.dev/models/vela-v4.2/model.bin.gz) |

如果單一服務每天產生數千次以上的模型下載請求，希望您能自行託管模型檔案並提供下載，感謝您的協助。

## 使用說明

瀏覽器會自動快取網頁圖片。若只更新網頁程式碼，會繼續使用已快取的圖片；圖片有變更時，只會重新下載有變更的檔案。清除網站資料後，則需要重新下載圖片。若要修改圖片，可參閱[圖片快取說明](../../src/content/IMAGE_CACHE.md)（韓語），了解如何產生及驗證雜湊清單。

操作方式與快捷鍵可在工具的說明頁面查看；簡體中文介面的按鈕名稱為「帮助」。遇到問題時，請在該頁面底部依序選擇「保存诊断信息」→「保存文件」，將儲存的檔案與問題發生時的情況一併提供。診斷檔案不會自動傳送。

## 模型研究與建置

[研究概覽](../../research/README.md)（英語）介紹 X36 → VELA → LYRA 的演進、主要轉折與評估結果。[環境與計算量](../../research/topics/environment.md)（韓語）說明有限資源 MDP 的數學模型、狀態空間、搜尋分支數及 Oracle 實驗。

模型產生、訓練與轉換流程請從[重現指南](../../research/reproduction/README.md)（英語）開始。LYRA v1 的 V₂₀ 訓練程式碼，以及轉換為瀏覽器用 FP32 模型的程式碼與步驟，請參閱 [LYRA v1 指南](../../research/lyra-v1/README.md)。工具採用 π₂₀ 單步策略。

VELA v4.2 的 FULL100 產生程式、Hinge 訓練程式碼與最終結果摘要，請參閱[VELA v4.2 指南](../../research/vela-v4.2/README.md)；WASM 建置方式請參閱[建置指南](../../src/policies/vela/native/README.md)。執行工具不需要 FULL100 原始表。各模型的詳細指南與 WASM 建置指南皆為韓語。
