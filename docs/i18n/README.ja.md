# ラテールアドベンチャー攻略アシスト | AIによるサイコロ・カードのおすすめ

[한국어](../../README.md) · [English](README.en.md) · **日本語** · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md)

ラテールアドベンチャーで、次にサイコロを振るか、どのカードを使うかを提案するWebアプリです。共有したゲーム画面を読み取る**アシスト**、ゲームの状態を自分で入力する**手動**、選んだサイコロ・カードの結果をアプリ内で再現する**自動**の3つのモードがあります。実際のゲーム操作はプレイヤー自身で行います。

アシストモードの**音声ガイド**は韓国語・英語・日本語・中国語に対応し、女性・男性の声を選べます。音声パックは容量を確認してからダウンロードでき、ブラウザーへの保存や削除も可能です。ガイド音声はGemini 3.8 Flash TTSであらかじめ生成したAI音声です。

## モデルを選ぶ

| モデル | 評価方法 | 平均スコア |
| --- | --- | ---: |
| **LYRA · v1（研究用）** | CPUまたはGPUでニューラルネットワークと1ステップ探索を使って行動を評価 | 研究時の評価で約1,879点 |
| **VELA · v4.2** | CPUで先の展開を調べて行動を評価 | 約1,877点 |
| **X36 · G3** | CPUまたはGPUでシミュレーションを繰り返し、選択肢を比較 | 約1,860点 |

平均スコアは、それぞれ異なる条件で評価した参考値です。計算にかかる時間は、端末の性能やゲームの状況によって変わります。

初期設定ではVELAが選択されています。LYRAは研究用モデルで、実行デバイスを自動・CPU・GPUから選べます。自動では利用可能なGPUを優先し、準備や推論に失敗した場合はCPUに切り替わります。

初回の読み込みには、VELAで約**68 MB**、LYRAで約**31 MB**のモデルパッケージが必要です。公開サイトでは、ブラウザーへの保存に同意すると、次回から保存済みのモデルを再利用できます。最新のモデル情報を確認した時点で、互換性のない旧バージョンの保存データは削除されます。自分のPCで起動する場合はプロジェクト内のモデルファイルを使い、ブラウザーには重複して保存しません。LYRAはCPUとGPUを切り替えても同じパッケージを使います。

行動ごとの評価値は、各選択肢の有利さを表します。予想最終スコアは、選択したモデルのおすすめに従い続けた場合の見込みです。VELA v4.2とLYRA v1には、それぞれの方策に合わせて学習した専用のスコア予測器を使っています。ゲーム終了時には実際のスコアを表示します。モデル選択をキャンセルすれば、おすすめ表示なしでも利用できます。

## 自分のPCで起動する

**Node.js 22以降**があれば、追加のパッケージインストールやビルドは不要です。

1. プロジェクトをダウンロードして展開します。
2. 使いたいモデルを以下の**GitHub Releases**からダウンロードし、**解凍せずに**指定の場所へ置きます。X36 · G3だけを使う場合、この手順は不要です。
   - **[VELA v4.2](https://github.com/alfm201/adventure/releases/tag/vela-v4.2)：** `model.bin.gz` → `public/models/vela-v4.2/model.bin.gz`
   - **[LYRA v1 · 研究用プレリリース](https://github.com/alfm201/adventure/releases/tag/lyra-v1)：** `lyra-v1.bin.gz` → `public/models/lyra-v1/lyra-v1.bin.gz`
3. プロジェクトフォルダーでターミナルを開き、次のコマンドを実行します。

   ```sh
   node scripts/serve.mjs
   ```

4. ブラウザーで**[http://127.0.0.1:4173/](http://127.0.0.1:4173/)**を開きます。環境変数`PORT`でポート番号を変更することもできます。

`npm start`でも起動できます。利用中はターミナルを開いたままにし、終了するときは`Ctrl+C`を押してください。`index.html`をダブルクリックして直接開く`file://`形式には対応していません。

## 使い方・トラブル対応

画像はブラウザーに自動でキャッシュされます。ページのコードだけが更新された場合は保存済みの画像を再利用し、画像が変更された場合はそのファイルだけを再取得します。サイトデータを削除すると、画像の再ダウンロードが必要になります。画像を編集する際のハッシュ一覧の生成・検証方法は、[画像キャッシュの説明](../../src/content/IMAGE_CACHE.md)（韓国語）を参照してください。

操作方法やキーボードショートカットは、アプリの**ヘルプ**で確認できます。不具合が起きた場合は、ヘルプの下部にある**診断情報を保存 → ファイル保存**から保存したファイルを、発生時の状況とあわせてお送りください。診断ファイルが自動送信されることはありません。

## モデルの研究・ビルド

[研究概要](../../research/README.md)（英語）では、X36 → VELA → LYRAの系譜と主な転換点・評価結果をまとめています。[環境と計算量](../../research/topics/environment.md)（韓国語）では、有限資源MDPの数式、状態空間、探索の分岐数、Oracle実験を説明しています。

モデルの生成・学習・変換は、[再現ガイド](../../research/reproduction/README.md)（英語）を参照してください。LYRA v1のV₂₀学習と、ブラウザー向けFP32モデルへの変換コード・手順は、[LYRA v1のガイド](../../research/lyra-v1/README.md)にあります。アプリではπ₂₀の1ステップ方策を使っています。

VELA v4.2のFULL100生成、Hinge学習のコードと結果の概要は[VELA v4.2のガイド](../../research/vela-v4.2/README.md)、WASMのビルド方法は[ビルド手順](../../src/policies/vela/native/README.md)を参照してください。アプリの実行にFULL100の元テーブルは必要ありません。モデル別のガイドとWASMのビルド手順は韓国語です。
