# 페이지 언어

## 동적 문구

새 동적 문구는 `formatMessage(원문 키, ...값)`으로 번역표를 정확히 조회한 뒤 값을 대입한다. 일반 값은 파일명·모델명 등 데이터로 취급해 부분 번역하지 않는다. 번역할 값은 `message(원문 키, ...값)`으로 명시한다.

DOM에는 `setLocalizedText(node, 키, ...값)`, 접근성 설명에는 `setLocalizedAttribute(node, 속성명, 키, ...값)`을 사용한다. 예: `setLocalizedText(node, '{0} · 약 {1} 남음', speed, message('{0}초', seconds))`. 키·매개변수를 기존 WeakMap에 기억하므로 영어로 생성된 요소도 한국어·다른 언어로 다시 표시된다. 외부에서 해당 텍스트/속성을 덮어쓰면 이전 바인딩은 사용하지 않는다. HTML과 입력 값은 변경하지 않는다.

변하는 숫자를 번역 캐시에 누적하지 않으며 텍스트 노드를 재사용한다. 별도 타이머·전역 요소 목록·전체 화면 추가 순회는 없다. 기존 추정/부분 번역 경로는 호환용으로 유지하며 다운로드 시간·지원 설명·저장 파일 수·실시간 계산 안내·모델 준비 단계부터 명시적 경로를 사용한다.

## 기존 표시 경계

`messages.js`에 한국어 원문과 영어·일본어·중국어 간체 번역을 함께 관리한다. `{0}` 같은 치환 인자의 번호는 번역에서도 유지한다. 일부 맵 이름은 설명 번역 또는 음역이며 지역별 게임의 공식 표기 검증을 뜻하지 않는다.

`runtime.js`는 페이지의 표시 경계에서 텍스트 노드와 `aria-label`, `aria-description`, `title`, `placeholder`, `alt`, `data-label`만 번역한다. 원문과 마지막 표시값은 WeakMap에 보관한다. 원문으로 돌아가지 않고 번역문을 다른 언어로 다시 번역하는 방식은 사용하지 않는다. 새 문구는 MutationObserver에서 다음 화면 그리기 전에 반영하며, 전체 페이지 순회는 최초 시작과 언어 변경 시에만 수행한다. 일반 갱신은 바뀐 노드만 처리하고 번역 결과 캐시는 2,048개로 제한한다.

게임 명령·물리 카드 번호·인식 입력·모델 결과·음성 문장/언어는 바꾸지 않는다. 입력 필드의 값, `contenteditable`, `translate="no"`, 스크립트와 스타일도 제외한다. 새로 생성하는 동적 문구도 같은 카탈로그에 추가한다. HTML 조각은 `translateMarkup`으로 앱이 작성한 문구만 처리하고, 사용자 입력을 HTML로 삽입하지 않는다. 캔버스 대체 문구는 `translate`를 명시적으로 사용한다.

페이지 언어의 저장 키는 `adventure.page-language`다. 기본값은 한국어이고 지원 코드는 `ko/en/ja/zh`다. 브라우저 저장이 제한되어도 현재 접속에서 언어를 변경할 수 있다. `zh`의 문서 언어는 `zh-Hans`다. 언어 변경 이벤트는 표시와 캔버스만 갱신하며 게임 명령, 계산 재시작, 화면 공유 재연결을 호출하지 않는다. 카드 검색은 기존 한국어·효과 표현과 현재 페이지 언어의 카드 이름을 모두 허용한다.

이미지에 포함된 글자, 브라우저 자체 공유 선택창, 외부 문의 폼은 이 카탈로그의 대상이 아니다.

음성을 아직 적용한 적이 없고 꺼져 있으면, 음성 설정 창의 최초 언어 선택은 현재 페이지 언어를 따른다. 음성을 적용한 뒤에는 별도로 저장한 음성 언어를 유지한다. 기본 선택만으로 다운로드·재생하거나 음성 설정을 저장하지 않는다.

도움말의 강조·단축키가 포함된 문장은 전체 HTML 문구를 우선 번역하여 언어별 어순을 유지한다. 모델 선택 단계의 설정 진입은 선택창을 유지한 채 하위 모달을 열며, 비동기로 다른 창에 넘어가는 모델 준비 단계에서는 진입점을 숨긴다. 언어 저장 실패는 현재 접속에서의 변경을 막지 않고 설정 화면의 저장 안내에 반영한다.
